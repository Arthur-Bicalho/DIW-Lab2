# Diagramas em Mermaid

Status: aceita

Os diagramas ficam em `docs/diagramas/*.md` como blocos Mermaid. O GitHub renderiza Mermaid sem ferramenta extra, enquanto arquivos PlantUML exigiriam renderizador local. Mermaid não tem diagrama de casos de uso nativo, então ele é desenhado como fluxograma com atores e elipses.
