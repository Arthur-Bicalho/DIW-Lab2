# ADR 0000 – Skills de planejamento indisponíveis

**Status:** aceita

**Contexto:** o processo previa as skills `/setup-matt-pocock-skills`, `/to-spec`,
`/to-tickets`, `/implement` e `/improve-codebase-architecture`, que não estão
instaladas neste ambiente. Estão disponíveis `tdd`, `domain-modeling`,
`code-review`, `pr`, `diagnosing-bugs` e `codebase-design`.

**Decisão:** reproduzir manualmente o resultado das skills ausentes: a configuração
(GitHub Issues, rótulos `modelagem`, `feature`, `bug`, `docs`, documentação em
`/docs`), a especificação em `docs/SPEC.md`, os tickets como Issues do GitHub e as
revisões de arquitetura guiadas pelo vocabulário de `codebase-design`.

**Justificativa:** mantém o processo e a rastreabilidade pedidos pelo enunciado sem
depender de ferramentas ausentes.
